# Sistema de Avaliacao - Cartoes da Escola Sabatina

Este arquivo reune as perguntas que devem ser captadas no sistema. As datas impressas nos cartoes fisicos nao devem ser cadastradas como valores fixos; no sistema, use trimestre, semana do ano, numero do sabado ou campos de data preenchidos pelo usuario quando a propria pergunta pedir uma data.

## 1. Cartao do Aluno

Por enquanto, o aluno tera uma tela para visualizar suas respostas, progresso e futuras atividades. As respostas semanais do aluno serao coletadas pelo professor e salvas pelo professor no sistema. A tela do aluno deve ser atualizada a partir desses salvamentos.

**Pergunta 1:** Voce participou regularmente do Pequeno Grupo com os membros da classe?
- [ ] Sim
- [ ] Nao

**Pergunta 2:** Voce participou de uma acao solidaria para captacao de interessados?
- [ ] Sim
- [ ] Nao

**Campos adicionais:**
- Descreva a acao solidaria realizada: _________________________________________
- Tipo de acao (ex.: entrega de cesta basica, circuito de saude, visita a lar de idosos ou presidios etc.): _________________________________________

**Pergunta 3:** Voce ministrou, ou acompanhou, estudo biblico para alguem no decorrer desse trimestre?
- [ ] Sim
- [ ] Nao

**Coleta semanal feita pelo professor:**
- Estudou a licao durante a semana?
- Foi pontual no sabado?
- Observacoes da semana, quando necessario.

**Regra de exibicao para o aluno:**
- O aluno visualiza as respostas registradas pelo professor.
- Quando o professor salvar uma semana, os dados de estudo, pontualidade e progresso do aluno devem ser recalculados e exibidos na tela do aluno.
- O aluno nao edita essas respostas nesta etapa.

## 2. Cartao do Diretor

O diretor deve responder este conjunto uma vez por trimestre. No ano, serao 4 preenchimentos.

**Pergunta 1:** Avaliar e promover a Escola Sabatina como um todo e a execucao dos 10 itens do Projeto Professor Nota 10. Todas as classes estao cumprindo os 10 itens do Projeto Professor Nota 10?
- [ ] Sim
- [ ] Não
- [ ] Algumas

**Pergunta 2:** Realizar a Classe dos Professores. A Classe dos Professores foi realizada regularmente neste trimestre?
- [ ] Sim
- [ ] Não

**Subpergunta - Quem participou das reuniões?**
- [ ] Todos os professores
- [ ] Apenas parte da equipe
- [ ] Nenhum professor participou

**Pergunta 3:** Implantar a Classe dos Interessados. A Classe dos Interessados ja foi implantada na igreja?
- [ ] Sim
- [ ] Não

**Campo adicional:**
- Quantos alunos estao participando da Classe dos Interessados? _______ alunos atualmente.

**Pergunta 4:** Realizar o pastoreio, ou seja, visitar os professores pelo menos uma vez no decorrer do ano. Informe a primeira e a ultima visita realizada neste trimestre.
- Primeira visita: ___/___/___
- Ultima visita: ___/___/___
